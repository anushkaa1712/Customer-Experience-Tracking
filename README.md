# Customer-Experience-Tracking

## 📌 Project Overview
The Customer Experience Tracking System is a console-based Java application designed to collect, track, and analyze customer feedback and complaints.  
It helps administrators understand customer satisfaction levels and manage complaints efficiently.

---

## 🧩 Modules
1. **Admin Module**
   - Admin login
   - View all complaints
   - Update complaint status
   - View reports and analytics

2. **Customer Module**
   - Customer registration & login
   - Submit feedback (ratings & comments)
   - Generate complaints

3. **Complaint Module**
   - Store customer complaints
   - Track complaint status (Open / In Progress / Closed)

4. **Feedback Module**
   - Store customer feedback
   - Rating-based feedback analysis
